# speech-coach

Speech coach project. Repo: https://github.com/Suhasv1982/speech-coach

## Environment
- Python 3.11, virtual environment in `.venv/` (not committed)
- Activate: `.\.venv\Scripts\Activate.ps1` (Windows) or `source .venv/bin/activate` (Mac)

## Commands (with .venv active)
- Install: `pip install -r requirements-dev.txt`
- Run app: `streamlit run app.py` (or F5 "Speech Coach" in VS Code), then open http://localhost:8501
- Lint: `ruff check .` and `ruff format --check .`
- Test: `pytest`

## Modules
- `config.py` – settings from `.env`; data folders; `ffmpeg_exe()` (FFMPEG_PATH, then PATH, then imageio-ffmpeg)
- `assessment_tasks.yaml` + `tasks.py` – the five tasks and their validation
- `audio.py` – saves takes to `recordings/<session_id>/<task_id>.<ext>`, converts to `<task_id>_16k.wav`
- `storage.py` – SQLite (`data/speech_coach.db`): `sessions`, `tasks`, `metrics`
- `app.py` – Streamlit UI: start page, one page per task, summary
- `tests/` – no API keys; outbound network is blocked, so mock any API calls.
  `tests/fixtures/sample.wav` is regenerated by `tests/make_sample_wav.py`

## Working sitting
1. `git pull`
2. Activate `.venv` and confirm VS Code's interpreter is `.venv`
3. Commit and push at the end of each sitting

## Notes
- This is not a Databricks project; don't use Databricks tooling here.
