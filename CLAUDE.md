# speech-coach

Speech coach project. Repo: https://github.com/Suhasv1982/speech-coach

## Environment
- Python 3.11, virtual environment in `.venv/` (not committed)
- Activate: `.\.venv\Scripts\Activate.ps1` (Windows) or `source .venv/bin/activate` (Mac)

## Commands (with .venv active)
- Install: `pip install -r requirements-dev.txt`
- Run app: `streamlit run app.py --server.maxUploadSize 1024` (or F5 "Speech Coach" in VS Code), then open http://localhost:8501
- Lint: `ruff check .` and `ruff format --check .`
- Test: `pytest`; run it with `CLOUD_MODE=true` and `false` (CI does both)

## Modes
- Local (default): `medium.en` model, files in `recordings/`, SQLite, reports in `reports/`
- Cloud (`CLOUD_MODE=true`, for Streamlit Community Cloud): `small.en`/int8, temp files deleted
  after each analysis, no SQLite, results only in `st.session_state` plus downloads.
  Auto-on when the app runs from `/mount/src` (Community Cloud); secrets/env override.
  Deploy steps are in README.md.

## Dependencies
- Python 3.11 only (the app stops with a message on other versions).
- `requirements.txt` pins every runtime package, transitive ones included, to the versions
  in the working `.venv` (av 19 breaks faster-whisper 1.2.1). Upgrade deliberately and run
  `tests/test_pinned_stack.py`. `pyproject.toml` holds tool config only (no `[project]`).
- The real-model test needs `tiny.en` cached once:
  `python -c "from faster_whisper import download_model; download_model('tiny.en')"`

## Modules
- `config.py` – settings: `st.secrets`, then env/`.env`, then defaults (`get_setting`, `cloud_mode()`,
  `whisper_settings()`); `settings_summary()` logs sources only, never values; `ffmpeg_exe()`
- `assessment_tasks.yaml` + `tasks.py` – the five tasks and their validation
- `audio.py` – saves takes to `<base_dir>/<session_id>/<task_id>.<ext>`, converts to `<task_id>_16k.wav`, `cleanup()`
- `speech_model.py` – loads faster-whisper (lazy import) and returns a `Transcript`
- `analysis.py` – metrics: duration, word count, words per minute, reference coverage
- `pipeline.py` – `process_take()`: save → convert → transcribe → metrics → store (local) / delete (cloud)
- `report.py` – Markdown report and metrics JSON
- `storage.py` – SQLite (`data/speech_coach.db`): `sessions`, `tasks` (with transcript), `metrics`
- `app.py` – Streamlit UI: start page, one page per task, summary with downloads
- `tests/` – no API keys; outbound network is blocked, so mock any API calls; `fake_model` fixture
  stands in for Whisper. `tests/fixtures/sample.wav` is regenerated by `tests/make_sample_wav.py`
