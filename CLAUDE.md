# speech-coach

Speech coach project. Repo: https://github.com/Suhasv1982/speech-coach

## Environment
- Python 3.11, virtual environment in `.venv/` (not committed)
- Activate: `.\.venv\Scripts\Activate.ps1` (Windows) or `source .venv/bin/activate` (Mac)

## Working sitting
1. `git pull`
2. Activate `.venv` and confirm VS Code's interpreter is `.venv`
3. Commit and push at the end of each sitting

## Notes
- This is not a Databricks project; don't use Databricks tooling here.
- Keep secrets in `.env` (git-ignored), never in code.
